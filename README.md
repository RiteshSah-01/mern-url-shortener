# MERN URL Shortener

A full-stack URL-shortener web built using the MERN stack.

## Features
- Shorten long URLs
- QR Code generation
- Copy shortened URL
- Download QR Code
- URL validation
- Responsive UI

## Tech Stack
- React + Vite
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- DaisyUI

## Installation

```bash
git clone https://github.com/RiteshSah-01/mern-url-shortener.git
cd mern-url-shortener
npm install
```
